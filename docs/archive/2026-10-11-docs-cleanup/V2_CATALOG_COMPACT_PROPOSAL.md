# Главная и компактные каталоги v2 — согласованный план

7 октября 2026, Новосибирск. Пользователь предложил заменить крупные карточки работ и мастеров на главной моушн-графикой и крупными переходами в разделы; в каталогах показывать превью с краткими сведениями. На присланном мобильном скриншоте одна карточка салона занимает почти весь экран. Запрошены мнение и удобная навигация для растущего каталога; последующим «ок :)» пользователь согласовал начало с компактного каталога мастеров/салонов. Первый блок опубликован как `20261007-v2-compact-catalog`; отчёт: [RELEASE_20261007_COMPACT_CATALOG.md](<../../RELEASE_20261007_COMPACT_CATALOG.md>).

## Компоновка — три блока опубликованы

- Главная: после выбора редакционного концепта опубликована композиция с целым зелёным узором под текстом слева и отдельной фотографией справа. Основное действие ведёт к мастерам/салонам; ниже два заметных входа в работы и карту. Наложение SVG на фото отменено, сохранены лёгкие реакции кнопок и компактность телефона. Отчёт: [RELEASE_20261007_HOME_EDITORIAL.md](<../../RELEASE_20261007_HOME_EDITORIAL.md>). Финальное промо из профилей/работ не делать из текущих выдуманных записей команды.
- Каталог мастеров/салонов: компактное превью без высокой декоративной обложки. Фото/логотип, имя, тип страницы, город/район, направления, рейтинг при наличии, цена и действие записи. Различия брендов сохранить через цвет, тип и портрет/логотип при равной заметности. На десктопе предложена сетка 3–4 колонки; на телефоне удобнее горизонтальные компактные карточки в одну колонку. Две колонки мастеров — вариант для сравнения, не утверждённое требование.
- Каталог работ: опубликованы превью с короткой подписью и автором, до восьми работ на странице; по уточнению пользователя четыре колонки и два ряда на компьютере, две колонки на телефоне. Полное фото открывается при выборе. Прежнее увеличение каждой седьмой карточки убрано; размеры одинаковые.
- Кнопки и подписи оставлять читаемыми; основной путь к записи не удлинять ради плотности.

## Навигация — оба каталога опубликованы

Поиск и «Фильтры» доступны при листании; город, направление и дата задаются явно. Сохранять условия в адресе страницы, загруженную часть каталога и положение прокрутки при возврате из профиля/работы. Понятные состояния загрузки, повтор при ошибке и конец выдачи; не выдавать неизвестное общее количество за точное.

Для мастеров/салонов опубликованы ограниченные страницы: 12 обычных результатов на телефоне и 24 на десктопе. Крупные «Назад / Страница N / Далее»; текущий сервер использует курсор, произвольных прыжков по неизвестным страницам нет. По последующему уточнению пользователя каталог работ также получил ограниченные страницы до восьми работ вместо «Показать ещё», вместе с восстановлением места просмотра.

В каталоге мастеров теперь ограниченные страницы 12/24, курсоры и номер в URL, история для «Назад», поиск/фильтры в URL и восстановление положения при возврате из профиля. Прямые ссылки без истории предлагают «К началу»; произвольных прыжков по неизвестным страницам нет. Каталог работ по последующему уточнению пользователя также получил ограниченные страницы до восьми работ, сетку 4×2 на компьютере/две колонки на телефоне, URL и восстановление положения; прежнее «Показать ещё» заменено листанием. Главная с крупными переходами и лёгкой SVG-анимацией также опубликована как `20261007-v2-home-inspiration`; отчёт: [RELEASE_20261007_HOME_INSPIRATION.md](<../../RELEASE_20261007_HOME_INSPIRATION.md>).
