## 2. Требования к окружению (shadcn / Tailwind / TypeScript)

### Почему важна папка `/components/ui`
В экосистеме **shadcn/ui** папка `components/ui` является общепринятым стандартом де-факто:
1. **Соглашение путей (Path Aliases)**: CLI shadcn по умолчанию настраивает алиас `@/components/ui`. Все сторонние компоненты (Magic UI, 21st.dev, Aceternity) ориентируются на этот путь.
2. **Разделение слоёв**: Базовые примитивы интерфейса (кнопки, меню, диалоги) изолируются в `components/ui`, а составные страницы и модули хранятся уровнем выше в `components/` или `app/`.
3. **Обновляемость**: Код в `components/ui` принадлежит вашему проекту, не скрыт в `node_modules` и может модифицироваться под фирменный стиль.

### Инструкция по настройке shadcn в проекте (если подключается React-стек)
1. **Инициализация TypeScript и Tailwind CSS**:
   ```bash
   npm install -D typescript @types/react @types/node tailwindcss postcss autoprefixer
   npx tailwindcss init -p
   ```
2. **Инициализация shadcn**:
   ```bash
   npx shadcn@latest init
   ```
3. **Установка зависимостей компонента**:
   ```bash
   npm install react-icons
   ```

## 3. Анатомия визуального эффекта (как это работает)

Меню построено на интерактивной трансформации капсулы:
1. **Круг в покое**: `w-[60px] h-[60px] rounded-full` — видна только серая иконка по центру.
2. **Раскрытие по наведению**: `hover:w-[180px]` с плавной анимацией `transition-all duration-500`.
3. **Градиент и свечение (Glow effect)**:
   - Псевдоэлемент с градиентом от `var(--gradient-from)` к `var(--gradient-to)` плавно появляется с `opacity: 100`.
   - Задний слой с `blur-[15px]` создаёт мягкий неоновый ореол вокруг плашки.
4. **Смена контента**:
   - Иконка плавно уменьшается до нуля: `group-hover:scale-0 delay-0`.
   - Название пункта плавно увеличивается из центра: `scale-0 group-hover:scale-100 delay-150`.

## 4. План адаптации для «Ателье» (Pure CSS + Vanilla JS)

Так как текущий пилот «Ателье» работает на сверхбыстром легковесном нативном PWA (без оверхеда сборщиков), этот эффект можно реализовать **в чистом CSS** без обязательного подключения React/Tailwind:

### Вариант 1. Десктопная шапка (`.desktop-nav`)
Пункты нашего меню:
* **Мастера** (иконка сетки / каталог мастеров)
* **Вдохновение** (иконка фото / лента работ)
* **Карта** (иконка геометки)
* **Календарь** (иконка календаря / расписание)
* **Моё** (иконка сердца / профиль и сохранённое)

Палитра адаптируется под фирменные оттенки «Ателье»:
* Винный/Бордо (`#65182d` → `#84263e`)
* Изумрудный (`#173f35` → `#2d5c50`)
* Тёплое золото/песочный (`#b49a65` → `#d3bc8e`)

### Вариант 2. Мобильный нижний бар (`.bottom-nav`)
На смартфоне наведение курсора отсутствует (hover), поэтому механика адаптируется под **активный таб**:
* Активный пункт меню автоматически раскрывается в капсулу со словом и градиентным свечением.
* Неактивные остаются компактными круглыми иконками.
* При переключении вкладка мягко расширяется, а предыдущая сжимается в кружок.
