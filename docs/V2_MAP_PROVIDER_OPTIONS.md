# Карта Luma — сравнение провайдеров и подключение Яндекса

Проверено по официальным источникам **14.10.2026**, Asia/Novosibirsk. Задача [U-09-04](tasks/U-09-04.md). Пользователь выбрал «Сначала показать сравнение», затем попросил изучить Яндекс Карты с адресными точками мастеров/салонов. **Смена провайдера не согласована и не выполнена.**

## Варианты

| Вариант | Что даёт Luma | Что потребуется |
| --- | --- | --- |
| Текущий Leaflet + OSM | Уже работают наши точки, группы, фильтры, карточки и история | Остаются правила публичного сервиса тайлов; растровую подложку нельзя перекрасить по отдельным типам объектов |
| MapLibre + OpenFreeMap | Векторная светлая карта в цветах Luma, управление подписями/слоями | Адаптация движка и проверка WebGL/производительности; публичный OpenFreeMap сейчас не требует ключа. Реальные снимки сравнения готовы |
| Leaflet + Яндекс Tiles API | Подложка Яндекса при сохранении текущего движка и собственных точек | Ключ именно Tiles API, атрибуция/логотип Яндекса, обработка лимита. Это растровая схема с предопределёнными видами, не произвольный векторный стиль |
| Яндекс JavaScript API 3 | Векторная карта, собственные HTML/SVG-маркеры и кастомизация дорог/домов/подписей | Ключ JS API с HTTP Referer, адаптация движка и повторная проверка всех сценариев. Условия бесплатного/платного использования проверяются для выбранного продукта |

[Снимки текущей карты и OpenFreeMap](ui-concepts/2026-10-14-luma/map-provider-review-01/README.md) получены в одной работающей компоновке, с синтетическими анкетами. OpenFreeMap показан только предварительным слоем: его движок ещё не интегрирован в приложение. Реального снимка Яндекса в Luma пока нет: ключ проекта не подключён. Другой сервис не выдаётся за Яндекс.

## Как добавить мастеров и салоны на Яндекс

1. Подключить выбранный продукт в [кабинете разработчика](https://developer.tech.yandex.ru/). Для JS API 3 настроить HTTP Referer: рабочий домен и localhost разработки. Ключ браузерного API ограничить доменами; серверный signing secret, если используется подпись Tiles, браузеру не передавать.
2. Сохранить текущие `/api/map/viewport` и `/api/map/details`. На карту отправляются только публичные опубликованные места и сохранённые координаты. Сотрудники остаются внутри салона. Контакты клиентов, заявки и внутренние заметки на карту не отправляются.
3. Для Tiles заменить источник тайлов, сохранив Leaflet и наши SVG-капли. **Обязательно `projection=web_mercator`** для текущей проекции Leaflet: у Яндекса по умолчанию эллиптическая проекция, простая замена URL без параметра может сместить адресные точки. Нужны ключ, `lang=ru_RU`, `x/y/z`, `l=map`, выбранный поддерживаемый `maptype`. Не применять неофициальные tile URL.
4. Для JS API использовать `YMap`, `YMapDefaultSchemeLayer`, `YMapDefaultFeaturesLayer`, `YMapMarker`; координаты передавать как **[долгота, широта]**. Содержимое маркера — наш статический SVG, подписи через textContent. Клик выбирает существующую карточку Luma с рейтингом, ближайшим временем и записью. Перемещение/zoom карты запускают прежний viewport-запрос. Нашу серверную группировку сохранить, не накладывать второй независимый clusterer.
5. Геокодирование при открытии карты не нужно: координаты уже сохранены. Отсутствующую/неподтверждённую точку не заменять соседним домом или центром города. Новое подтверждение адреса — отдельная F-01. Наличие маркера Luma не означает регистрацию организации в Яндекс Бизнесе.
6. Сохранить фильтры/выбор/область и Back, ручное «Показать ещё», mobile карту/список, loading/error/retry, геолокацию, reduced-motion и читаемую обязательную атрибуцию. Проверить точку конкретного дома при нескольких масштабах, 320/390/800/1440 px, отказ ключа/сети/лимит и переход в запись салона с сотрудником.

## Тарифы и данные

По официальной странице Tiles API на дату проверки: бесплатное коммерческое/некоммерческое использование при соблюдении условий, **до 30 запросов тайлов в секунду**. Это запросы картинок, не 30 посетителей; загрузка одной карты требует нескольких тайлов. При росте требуется оценить общую нагрузку. Логотип Яндекса со ссылкой обязателен. [Возможности и условия Tiles](https://yandex.ru/maps-api/products/tiles-api), [ограничения и логотип](https://yandex.ru/maps-api/docs/tiles-api/index.html).

У JS API, Геокодера и Tiles разные условия. Тарифная страница JS API отдельно указывает вариант без рекламы **2 000 ₽/месяц или 20 000 ₽/год за один домен**; это не универсальная цена всех API/лицензий. Покупку пользователь не поручал. Перед выбором проверить действующие условия именно своего проекта и продукта в кабинете. [Тарифы](https://yandex.ru/maps-api/tariffs).

Не переносить результаты Яндекс Геокодера в постоянную БД автоматически: для полученных от Яндекса данных действуют отдельные ограничения использования/хранения. Наши существующие координаты не требуют повторного получения через Яндекс. [Условия сервисов](https://www.yandex.ru/legal/maps_api/ru/).
