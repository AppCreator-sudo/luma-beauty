## Контракт реализации

1. Оба типа используют PublicPageCover/PublicPageIdentity/ProfileBadges/PublicReviews и один public-page-identity.css. На desktop фото слева, название/данные рядом, запись/сердце/share горизонтально справа. Mobile — фото с именем, сведения на всю ширину, затем единая строка действий. Удалены пустые боковые поля салонной центрированной колонны и декоративный разделитель.
2. Общая обложка с прежним текстом «Красота в деталях». Исходный ornament.webp сохранён; вывод одного изображения cover/no-repeat устраняет стыки, палитра теперь видна. Светлая/винная/зелёная доступны обоим типам; у старого салона default green сохраняет прежний фон. Загруженное фото имеет приоритет над цветом — как у существующего редактора мастера.
3. CabinetIdentity для самостоятельного мастера/салона использует те же cover/identity; preview показывает оформление, не подставляет вымышленные отзывы/услуги. Полные отзывы/услуги/команда — на странице. Staff сохраняет действующий редактор и принадлежность салону.
4. Мастер: «Обучаю» и «Ищу моделей»; салон: «Обучаем» и «Ищем моделей». Чекбоксы доступны только владельцу соответствующей страницы. Поиск моделей default off и не обещает бесплатную услугу/скидку. Обучение салона — самостоятельная настройка владельца; миграция сохраняет существовавший показ по активным публичным сотрудникам, дальнейшее изменение сотрудников не переключает её автоматически.
5. Общий рейтинг и список отзывов: одна реальная оценка завершённого клиентского визита 1–5, совпадающие master/client, место салона по booking_venues. Старые личные визиты сотрудника не становятся салонными, перевод сотрудника не переносит историю. Нет оценок — «Пока без оценок». Публичный список до 20 последних по одному стандарту; новые способы оценки не создаются. Средняя/число по всем подходящим отзывам, не только первой двадцатке. Каталог показывает реальный салонный рейтинг тоже.
6. Сердце мастера сохраняет действующую подписку follows. Сердце салона — отдельное saved_salons, без изменения подписок и без автоматической рассылки. Гостю вход с возвратом; сохранение/удаление повторяемы, видны только своему аккаунту. Чужой скрытый салон не выдаётся в библиотеке и не сохраняется; собственное сохранение скрытого салона можно удалить. Аккаунт клиента: «Мои мастера» → «Мастера и салоны»; работы остаются отдельно, экспорт включает свои salon_id/created.
7. Наполнение различается: мастер — портфолио/услуги/отзывы/о мастере; салон — услуги/команда/работы/отзывы/о салоне, публикации и фильтр автора сохраняются. Оба имеют ближайшее окно в одинаковом блоке справа на desktop и перед основным содержимым на mobile. Салонные слоты/запись остаются через действующий API с выбором конкретного/любого сотрудника. При смене услуги не выдавать время старой услуги; ошибки проверки времени допускают повтор.

## Данные и совместимость

Аддитивная миграция profile-page-options-v1: profiles.looking_models; workspaces.theme/teaches/looking_models; saved_salons с FK user/workspace, каскадным удалением и уникальной парой. Снимок VACUUM INTO до изменения, транзакция и идемпотентность. Старые изображения, подписки и визиты сохраняются. Валидация boolean/палитры, пропущенные новые опции сохраняют прежние значения. API страницы салона дополнен theme/flags/rating/review_count/reviews/saved; `/salons/:id/save` POST/DELETE; `/library.salons`; экспорт клиента. Никаких новых платежей/ролей/провайдеров карты/БД.
