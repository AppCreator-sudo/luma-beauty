## Порядок работы

1. Work in → Cloud → Create environment, выбрать private luma-beauty, Get started.
2. Передать готовый запрос настройки из CODEX_CLOUD. Установить зависимости; использовать только новую .local-data/cloud и локальные переменные.
3. Проверить setup report: install/build/docs, запуск /api/health и /v2/, доступность браузера и реальный preview origin.
4. Ограничения записать точно. Не исправлять приложение/tests во время настройки; известные BUG-002…005/CHECK-001 уже отдельные карточки.
5. Save/Publish, зафиксировать реальный Environment published, имя среды и фактическое время. Секреты не записывать.
6. После явного продолжения разработки открыть [U-09-01](U-09-01.md); восстановить её как next_task_id и обновить checkpoint/state/roadmap.
