## Граница задачи

Создать среду для закрытого [AppCreator-sudo/luma-beauty](https://github.com/AppCreator-sudo/luma-beauty), проверить Linux setup report и опубликовать среду. Это не запуск разработки UI и не production-выпуск. Готовый GitHub уже подтверждён; облачная среда ещё не создана/опубликована.

## Зависимости и разрешение

[OPS-02](OPS-02.md). Пользователь продолжает настройку в своём Codex Cloud и при запросе сам разрешает GitHub-интеграции доступ к этому private репозиторию. Пароль/токен не отправлять в чат. Не создавать новые чаты и не расширять доступ интеграции без соответствующего запроса пользователя.

- [AGENTS](../../AGENTS.md), [checkpoint](../WORK_CHECKPOINT.md).

## Порядок работы

1. Work in → Cloud → Create environment, выбрать private luma-beauty, Get started.
2. Передать готовый запрос настройки из CODEX_CLOUD. Установить зависимости; использовать только новую .local-data/cloud и локальные переменные.
3. Проверить setup report: install/build/docs, запуск /api/health и /v2/, доступность браузера и реальный preview origin.
4. Ограничения записать точно. Не исправлять приложение/tests во время настройки; известные BUG-002…005/CHECK-001 уже отдельные карточки.
5. Save/Publish, зафиксировать реальный Environment published, имя среды и фактическое время. Секреты не записывать.
6. После явного продолжения разработки открыть [U-09-01](U-09-01.md); восстановить её как next_task_id и обновить checkpoint/state/roadmap.

## Приёмка

Подтверждены выбранный private репозиторий, отчёт настоящей Linux-проверки и публикация среды. Базовая среда не содержит production данных. Пользователь отдельно разрешил полный защищённый пакет OPS-04; при его импорте среда Only me, ключ вне Git и безопасная рабочая копия по CLOUD_SERVER_ACCESS. Концепты/навыки доступны из checkout; UI и тесты не переделаны настройкой.
