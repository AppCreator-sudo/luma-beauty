## Граница задачи

Тесты ожидают новую выдачу приглашения 201, текущий согласованный API возвращает 410 (owner-only). Сохранить проверку отказа новой выдачи и отдельно legacy-совместимость старых связей/ссылок. Не возвращать функцию ради зелёного теста.
