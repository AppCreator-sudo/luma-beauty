# BUG-017 — Портфолио: сетевой отказ показывает технический текст на английском

Статус: **Опубликовано** (`published`). Обновлено 2026-10-18T21:31:10+07:00, Asia/Novosibirsk.

## Граница задачи

WorkUpload передаёт TypeError.message без перевода при разрыве сети, в результате русская форма показывает Failed to fetch. До исправления установлено по обработчику TypeError.message; после исправления сетевой сценарий проверен браузером. Обычные серверные сообщения сохраняются.

## Зависимости и разрешение

[U-10-18](U-10-18.md); текущая приёмка [U-10-04](U-10-04.md). Очевидное исправление сообщения уже согласованного UI, без нового концепта/бизнес-действия.

## Что читать и какие навыки взять

[UI implementation](../../.agents/skills/atelier-v2-ui-implementation/SKILL.md), [WorkUpload](../../frontend/src/components/WorkUpload.tsx), [приёмка](U-10-04.md).

## Порядок работы

Для TypeError показывать понятное русское сообщение с повтором, сохранить отдельные сообщения API и прежние данные. Проверить POST network rejection в браузере на отдельной базе.

## Приёмка

Русский alert, выбранные услуга/фото/подпись сохранены, повтор доступен; успешный повтор создаёт одну работу. Встроенное создание услуги использует тот же fallback. Серверные тексты не подменяются.
