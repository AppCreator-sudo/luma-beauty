# BUG-019 — Мобильное боковое меню: фризы анимации и смена кнопки закрытия

Статус: `in_progress` — оптимизация текущей реализации. Оформлено 2026-10-19T12:00:34+07:00, Asia/Novosibirsk.

## Граница задачи

По сообщению пользователя18.10.2026 при открытии правого бокового меню на мобильном телефоне анимация сильно фризит. Второй симптом при закрытии: кнопка с горизонтальными полосами появляется раньше, чем исчезает крестик закрытия; смена элементов выглядит несогласованной. Зафиксированы два симптома одного элемента, без установленной причины.

Устройство уточнено пользователем19.10: Realme GT Master Edition, Android, Google Chrome155.0.8059.39. По его сообщению меню одинаково туго работает во всех разделах сайта, включая кабинет. Точная версия Android пока не указана. Сначала воспроизвести общую механику; не считать эмуляцию доказательством плавности на реальном телефоне. Проверить общую механику публичного меню и правого drawer кабинетов, определить затронутый вариант. Сохранять утверждённую концепцию, цвета, содержание и действующие переходы.

## Порядок работы

1. Воспроизвести оба симптома, записать маршрут/устройство/браузер и короткое видео либо замеры кадров открытия/закрытия. Разделить наблюдение пользователя и подтверждённый результат.
2. Проверить стоимость анимации и синхронизацию exit-перехода, dialog и кнопок. Причину устанавливать по измерениям; не менять принятую концепцию по предположению.
3. Проверить обычное закрытие, быстрое повторное нажатие, открытие во время закрытия, Back, Escape, затемнение, восстановление фокуса и позиции прокрутки, reduced motion. Desktop проверить на регрессию общей механики.
4. При подтверждённом баге подготовить исправление существующего поведения; изменение концепции сначала согласовать. Провести только целевые проверки, обновить карточку/реестр/checkpoint; не выполнять остальную очередь автоматически.

## Приёмка

Открытие и закрытие проходят без воспроизведённых сильных рывков на проверенном устройстве; результат подкреплён записью/профилированием с указанными условиями. Смена крестика и кнопки с полосами согласована со всей анимацией: нет наблюдаемого наложения двух состояний и недоступного закрытия. Сохранены44px действия, отсутствие overflow, scroll lock, Back/Escape/focus и reduced motion. Нельзя объявлять плавность подтверждённой только по сборке, статическому снимку или desktop-эмуляции. При недоступности физического устройства явно оставить этот предел проверки открытым.
