# BUG-011 — Публикация мастера отклоняет сменный график и исключения

Статус: **Опубликовано** (`published`). Обновлено 2026-10-15T22:26:33+07:00, Asia/Novosibirsk.

[Общий список](README.md) · [U-10-02](U-10-02.md) · [Результаты](../ui-checks/2026-10-15-master-onboarding/README.md)

## Граница задачи

Новый мастер с сохранённым циклом 2/2, недельным графиком с исключением или только отдельной рабочей датой не мог открыть страницу через PATCH /api/profile/publication. UI уже использовал scheduleHasWork, сервер проверял legacy master_schedules.weekdays, намеренно пустой для современных графиков. Отказ 400 воспроизведён HTTP-тестом и браузером до правки.

## Зависимости и разрешение

[U-10-12](U-10-12.md)

В рамках явной U-10-02 исправить очевидный дефект принятого графика без нового UI: использовать scheduleHasWork(schedule.config(userId)), сохранив отдельное требование явно сохранённого master_schedules и услуги. Права, транзакция, схема и остальные данные не меняются. Выпуск не входил в эту локальную приёмку.
