# BUG-018 — Вход и регистрация: скачки композиции при переключении

Статус: **Опубликовано** (`published`). Обновлено 2026-10-18T21:31:10+07:00, Asia/Novosibirsk.

## Граница задачи

Пользователь приложил два снимка /v2/auth и указал, что при переключении «Войти / Создать аккаунт» UI сильно двигается. Устранить непреднамеренное перемещение заголовков/вкладок/левой композиции и desktop-полей, сохранив утверждённые шрифты, роли, провайдеры и вход. Mobile сохраняет компактную вертикальную роль: её появление локально раскрывает содержимое, без 180px пустого места во входе.

## Зависимости и разрешение

[U-07N](U-07N.md) опубликована. Прямое текущее сообщение пользователя разрешает исправление очевидного бага существующей композиции; новый концепт и бизнес-действия не вводятся. Следующая плановая U-10-06 временно уступила этой конкретной задаче.

## Порядок работы

Зафиксировать baseline на текущей реализации → стабилизировать общий intro, размеры desktop/место роли, привязку карточки → проверить переходы/Back/фокус/поля/scroll desktop и mobile → обновить документы. Историю и состояние полей не перемонтировать. Не возвращать scrollbar-gutter:stable.

## Приёмка

Desktop: общие якоря/левая композиция/размер страницы не меняются при переключении. Mobile: intro/вкладки/арт стабильны, ниже добавляется только фактический блок ролей с плавным раскрытием и reduced-motion. Нет скрытого фокуса/overflow, действия 44px, поля/пароль/роль/Back сохранены. Signed-in/recovery/returnTo не получают чужие резервы. Обе сборки и целевой браузерный проход; без реальных API-записей.

## Локальный результат — 18.10.2026

Стабильные отдельные CSSgrid-области заголовка и описания учитывают оба варианта текста. Карточка привязана к верху; desktop резервирует 68px места выбора роли без доступных скрытых кнопок. Общая высота не меняется, поэтому орнамент и его заголовок остаются неподвижными. На mobile блок ролей раскрывается на 180px внутри содержимого с переходом 180ms; скрытый login не содержит180px пустоты. Reduced motion убирает анимацию. Это ожидаемая локальная вставка, не обещание нулевого движения всех полей на mobile.

Auth.tsx и auth-reference.css; роли/API, введённые поля, видимость пароля, Back/Forward и существующий возврат сохранены. Recovery/signed-in не получают auth-entry/role-reserve. Клавиатурная рамка роли расположена внутри кнопки и не обрезается при раскрытии. Scrollbar-gutter не добавлен, утверждённые PNG не изменены.
