## Граница задачи

Пользователь хочет убрать простой пароль после настройки новых способов. Сейчас удалять его нельзя: старые аккаунты должны сохранить доступ.

## Порядок работы

1. Предложить план привязки существующих аккаунтов/восстановления и критерии безопасного отключения.
2. Согласовать переход, проверить реальные провайдеры и recovery для всех ролей.
3. Отключить согласованную старую форму только после проверки перехода; зафиксировать совместимость и откат.

## Приёмка

- Ни один существующий аккаунт не лишён доступа; пароль удалён только после явного решения о переходе.
- Регистрация трёх ролей/ссылки/восстановление/сеансы работают.
