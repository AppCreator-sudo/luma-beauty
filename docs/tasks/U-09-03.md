## Граница задачи

Прямое поручение 14.10.2026: добавить реальные рейтинг/число отзывов и «Пока без оценок» для мастера и салона, исправить овальные значки до капель. Единый стандарт: отзыв после завершённого визита, оценка 1–5, одна оценка на визит; салон определяется сохранённым местом визита, не текущим составом сотрудников. Основная компоновка карты устраивает пользователя.

## Зависимости и разрешение

U-09-02 проверена локально. Новое поручение пользователя имеет приоритет над прежним исключением рейтинга из UI-этапа. Сохранение салона и остальные F-07 не разрешены этим уточнением. Production не выпускать в рамках подготовки сравнения.

## Что читать и какие навыки взять

Проектные product-design и ui-implementation, UI-журнал, U-09 review-01, фактический Map/viewport; F-07 для границ отзывов. Для провайдера — актуальные первичные документы OpenFreeMap/MapLibre.

## Порядок работы

1. Сверить текущий код и прямое решение пользователя.
2. Реализовать указанное уточнение либо подготовить сравнение без скрытой смены провайдера.
3. Проверить desktop/mobile, существующие функции и актуализировать документы.

## Приёмка

Без фиктивных оценок, без переноса отзывов сотрудников из других мест, без потери функций/данных. Маркер имеет острый кончик и корректную привязку. Смена подложки только после сравнения и решения; новые API-ключи/данные в Git не добавляются.
