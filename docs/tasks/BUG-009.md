# BUG-009 — Завершающий слеш нарушает выбор оболочки v2

Статус: **Готова к воспроизведению и работе по карточке** (`ready`). Обновлено 2026-10-15T21:12:10+07:00 (Asia/Novosibirsk).

[Список](README.md) · [Матрица U-10-01](../V2_REMAINING_UI_AUDIT.md)

## Граница задачи

Router принимает /masters/, /me/, /studio/, /calendar/, /salon/, но Shell.tsx сравнивает location.pathname с массивами/строками без завершающего слеша. Новая проверка установленным react-router-dom.matchRoutes дала true для каждого из пяти адресов, точное сравнение Shell — false. Публичный маршрут попадает в fallback site-header, кабинет может получить дополнительную общую шапку/footer. Последнее — вывод по JSX, новый screenshot ещё не получен.

## Зависимости и разрешение

[U-10-01](U-10-01.md) завершена. Аудит разрешал регистрацию дефекта, не выполнение всей очереди или публикацию. Нормализовать pathname для классификации оболочки либо выбрать эквивалентное сопоставление маршрутов. Корневую fullscreen-композицию, query/hash, BrowserRouter basename, Back и маршруты профилей/записи сохранить. Не добавлять redirect, теряющий параметры, или новую 404; не возвращать нижнюю панель.
