После поручения выполнить план выпуска: проверить actual version, свежий snapshot и dry run; собрать проверенный пакет; закрытый backup и короткая остановка; health/версия/сохранность/публичные GET; release-отчёт и GitHub SHA. Тестовые услуги/визиты не создавать на рабочем сайте. Не выводить секреты.

## Приёмка

Подтверждены фактический выпуск, целостность прежних данных/media, правильный UI и работа публичного выбора услуги/мастера/времени; указан безопасный откат с учётом новых записей. GitHub remote SHA подтверждён отдельно. Нет необоснованного объявления U-10/U-11 завершёнными.
