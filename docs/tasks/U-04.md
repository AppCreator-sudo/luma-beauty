## Граница задачи

Desktop — недельная сетка. Mobile — временная шкала дня, список недели, сетка месяца. Имя, услуга, дата/время, длительность, цена и заметки редактируются; контакт заявки только читается. Помещения и выбор напоминания не добавлялись.
