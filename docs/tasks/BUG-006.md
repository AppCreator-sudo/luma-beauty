## Граница задачи

Пользователь прислал сравнение «Вдохновение» / «Карта»: при переходе с мастеров/работ ссылки общей шапки смещаются по горизонтали. Исправить этот явный баг принятого UI, сохранив логотип, типографику, порядок ссылок, главную и функции карты. Проверить влияние обычной desktop-полосы прокрутки.

## Зависимости и разрешение

[U-09-05](U-09-05.md) опубликована 14.10.2026. Это исправление дефекта только что опубликованного UI в пределах разрешённой доводки карты; новый концепт/смена данных не требуются. Перед корректирующим выпуском проверить фактический current и сохранить предыдущую версию для отката.

## Порядок работы

1. Измерить координаты Brand, трёх ссылок и действий при переходах мастера → вдохновение → карта → обратно, включая desktop с обычной полосой прокрутки.
2. Исправить причину в общей оболочке публичных страниц, не подгонять каждую ссылку отдельными margin/transform. Домашнюю полноэкранную композицию не менять.
3. Проверить desktop/mobile, открытие/закрытие меню/фильтров, отсутствие переполнения и одинаковые координаты после переходов. Собрать frontend/root.
4. Выпустить точечную frontend-правку с новым SW-cache, сохранением старых assets и откатом без БД; записать реальную версию/проверки/даты.

## Приёмка

При одинаковом viewport ссылки общей шапки не смещаются между тремя разделами; Brand и действия сохраняют расположение. Mobile и главная не получают новую полосу/переполнение. Меню/Back работают. Backend, карта-провайдер и рабочие данные не меняются.
