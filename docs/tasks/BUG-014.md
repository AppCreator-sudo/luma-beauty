# BUG-014 — Портфолио: закрытие во время отправки позволяет создать дубль

Статус: **Опубликовано** (`published`). Обновлено 2026-10-18T21:31:10+07:00, Asia/Novosibirsk.

## Граница задачи

При удерживаемом POST внешний переключатель закрывает форму, уничтожает её lock; после открытия возможен второй одинаковый POST. Два объекта подтверждены на отдельной базе. Очевидный дефект существующего согласованного сценария U-10-04. Новый дизайн, бизнес-действия и структура данных не вводятся.
