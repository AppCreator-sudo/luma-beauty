# U-10-18 — Сетка портфолио и пошаговая загрузка работ мастера

Статус: `published`. Исполнитель: текущий чат pwa. Согласовано и начато 2026-10-15T18:03:46+07:00, опубликовано 2026-10-15T18:40:02+07:00, Asia/Novosibirsk.

## Граница задачи

Прямое поручение пользователя: исправить баг в кабинете индивидуального мастера (`/v2/studio?tab=works`), где работа растягивалась на всю ширину страницы, и привести к аккуратной сетке. Форму добавления работы перевести в компактный пошаговый вид с переключателем.

1. **Сетка портфолио**: ограничение растяжения через `repeat(auto-fill, minmax(180px, 240px))`, квадратная пропорция 1:1, hover-эффект, аккуратный заголовок с многоточием и доступная кнопка удаления 44 px. Одна работа больше не растягивается на 1100 px.
2. **Форма добавления работы**: кнопка-переключатель «Добавить работу» / «Закрыть форму» в шапке раздела, обёртка в компактную карточку с `max-width: 640px`, пошаговый мастер из 3 понятных шагов («Услуга», «Фото», «Подпись»), кнопки навигации («Отменить/Назад» слева, «Далее/Опубликовать» справа) и автоматическое сворачивание формы после публикации.
3. **Адаптивность**: проверено на desktop 1440px (ширина карточки 240px), mobile 390px (2 колонки по 153px, 0 overflow) и mobile 320px (2 колонки по 119px, 0 overflow).

## Зависимости и разрешение

Прямое поручение пользователя 15.10.2026 («в кабинете индивидуального мастера есть баг - портфолио занимает всю страницу...», затем «изменения задеплой на сервер,которые ты сделал для портфолио»).

## Приёмка

- Сетка работ не растягивает единственную работу на всю страницу; плитка имеет ширину 240 px на десктопе.
- Форма добавления по умолчанию скрыта при наличии работ и открывается по кнопке «Добавить работу».
- Форма имеет ширину до 640 px с аккуратной рамкой и фоном.
- Сенсорные цели от 44 px, переполнение по горизонтали 0 px на 1440, 390, 320 px.
- Frontend/root build PASS, ServiceWorker кэш обновлён, сервер опубликован без изменения базы данных и с сохранением резервной копии.
