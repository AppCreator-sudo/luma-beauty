## Порядок работы

1. Перевести действующие маршруты/фоновые операции на единый адаптер без изменения внешнего контракта.
2. Проверить общую занятость человека, уникальный pending перенос и повторную проверку окна при принятии.
3. Пройти прежние сценарии и настоящие конкурирующие PostgreSQL соединения.

## Приёмка

- Конкурентная запись/редактирование/перенос возвращают корректный конфликт без частичных обновлений.
- Все роли/гость/уведомления/экспорт/карта работают с единой базой, приватность сохранена.

## Фактические даты и результат

| Событие | Дата / факт |
| --- | --- |
| Согласование | Для выполненного — в источниках; для остатка отдельное уточнение ещё не записано |
| Начало | Не зафиксировано отдельно |
| Сделано локально | См. границу задачи; новая реализация не зафиксирована |
| Проверено | Не выполнено для этой задачи |
| Опубликовано | Отдельная публикация не зафиксирована / не применима |
| Будущий срок | Не назначен |
| Чат-исполнитель | Не назначен |
