# Простой кабинет салона — макет для обсуждения

**Предложение, не опубликованный интерфейс.** [Открыть кликабельный макет](index.html). [Сценарии и правила данных](../../V2_SALON_SIMPLICITY_PROPOSAL.md), [U-10-19](../../tasks/U-10-19.md).

Попробовать: изменить/назначить услугу → отметить Викторию → сохранить → «Мастера» → «Услуги» Виктории или «График». Изменения остаются в памяти макета и сбрасываются при перезагрузке. Имена/цены иллюстративные, API не вызываются. Ветка логотипа взята из действующего Brand.tsx; шрифты Manrope/Cormorant Garamond скопированы из существующей сборки в assets. Остальные разделы кабинета сохраняются, в макете показаны изменяемые связи.

[18 проверок макета](prototype-checks.json) PASS на 1440/390/320, JS errors0: назначение обновляет направления/список мастера, переход из карточки сохраняет сотрудника и открывает именно рабочий график, поля недельного/сменного режима согласованы, нет горизонтального переполнения. Это проверка прототипа, не реального сохранения/миграции приложения.
