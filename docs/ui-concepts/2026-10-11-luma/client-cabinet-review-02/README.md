## Утверждённые правила

- Перенос запрашивается для будущей активной записи. Меняются только дата/время, сохраняются мастер, услуга, длительность и цена. Один открытый запрос на визит; можно отозвать его и выбрать другое время. Исходный визит действует до принятия. Запрос не резервирует новое окно; мастер/владелец повторно проверяет его при принятии. Принятие подтверждает запись на новое время, отклонение/занятое окно оставляет исходную. Завершение или отмена исходной записи закрывает запрос.
- Комментарий клиента отделяется от рабочих заметок мастера. Для старых визитов, где разделения нет, общие заметки не показываются как «Ваш комментарий». Если исторический адрес не сохранён, отображается «Адрес уточните у мастера»; прошлый адрес не подменяется текущим.
- Личный профиль необязателен, не публикуется как страница мастера. Изменения не переписывают прошлые визиты; контакт передаётся при отправке заявки. Аватар использует действующие правила и круглый предпросмотр.
- «Мои данные» в первом выпуске — экспорт своих данных без паролей, кодов восстановления и секретных ключей гостевых записей. Удаление аккаунта требует отдельного решения о действующих визитах и истории, поэтому рабочего действия удаления в этом варианте нет.
- Восстановление сохраняет существующий механизм: логин, ранее выданный код, новый пароль. Провайдеры входа пока «Скоро». Реального списка устройств сейчас нет: доступно завершение других сеансов. Помощь — инструкции без вымышленного оператора поддержки.

## Проверка прототипа

Все состояния проверены в Chrome при ширине 1440, 390 и 320 px: нет горизонтального переполнения, нижней панели и ошибок страницы. [Результат](prototype-check.json). Это проверка макетов, не проверка серверных функций. Реальные сценарии, права, сохранение, reload и ошибки сети проверены в отдельной локальной базе; протокол указан в блоке реализации ниже. Блок решения переноса повторяется для мастера и владельца салона; в реализации он встраивается в утверждённые детали действующего календаря, не создаёт отдельный кабинет.
