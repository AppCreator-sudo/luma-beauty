## Утверждённые решения — 11 октября 2026

- Семь разделов: Обзор / Мои записи / Сохранённое / Мои мастера / Отзывы / Уведомления / Настройки.
- На телефоне четыре нижних пункта: Обзор / Записи / Сохранённое / Ещё; остальные разделы через Ещё. Детали — отдельный экран с возвратом в список.
- Утверждён новый приватный профиль клиента: необязательные имя/аватар/контакт/город; инициалы без фото. Профиль мастера для этого не используется.
- Утверждён центр событий, доступный при отключённых push. Push на устройстве включается/выключается отдельно; рекламных рассылок нет.
- Перенос утверждён запросом с подтверждением мастера или владельца салона; до принятия новое время не заменяет исходную запись. Текущий API клиента поддерживает отмену, а не перенос: серверную функцию нужно реализовать в U-08C.
- Дополнительные полезные сценарии: повтор по актуальным условиям, .ics, точный адрес визита, привязка своей гостевой записи, отзыв после завершённого визита, доступ/восстановление, управление своими данными и помощь.
- Утверждён отдельный этап U-08C: после каталога/портфолио U-07 и записи U-08, перед картой U-09. Сроки реализации/выпуска не назначены.

## Точность макетов и утверждённые уточнения

Фотографии, имена, места, цены и даты иллюстративные. В блоке «Мои мастера» используются действующие подписки самостоятельных мастеров; студийные подписи обзорной иллюстрации не означают новую функцию подписки на сотрудников. Уточнённый отдельный экран в `sections.png` показывает эту структуру без салонных подписей и имеет приоритет для блока обзора. Работы сотрудников в сохранённом сохраняют свой салон/автора.

На мобильном обзорном экране полоса уведомлений относится именно к push на текущем устройстве. Утверждён точный текст **«Push на этом устройстве выключены»**; уведомления внутри кабинета остаются доступными. В настройках утверждён текст **«Контакт передаётся при отправке заявки»** (уже показан в desktop-настройках), чтобы профиль не означал постоянный публичный показ данных.

Сохранённое: четыре desktop-колонки, две mobile. При нехватке места фильтры переносятся или прокручиваются внутри блока, а не расширяют всю страницу. Desktop/mobile одного сценария должны быть проверены вместе, действия от 44 px, нижняя навигация с safe-area без перекрытий, reduced-motion.

Отмена/повтор/отзыв зависят от реального статуса; скрытый исполнитель не удаляет историю. Перенос, профиль и inbox включены в утверждённый состав функций, но ещё не реализованы. Правила управления данными и недостающие формы/состояния требуют отдельного уточнения; изображение не подтверждает наличие функции в коде. Уточняющие состояния подачи запроса/подтверждения отмены/создания отзыва/безопасности нужно показать и согласовать перед их реализацией, без самостоятельной смены утверждённой компоновки.

Макеты пока не заменяют существующий клиентский `/v2/me`. Текущий выпуск — публичные страницы U-06. Ответы пользователя от 11 октября зафиксированы в этом файле, спецификации, roadmap и checkpoint. Утверждение макетов не означает завершение разработки или выпуск.
