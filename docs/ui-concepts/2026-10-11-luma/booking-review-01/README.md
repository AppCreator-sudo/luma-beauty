Зелёная шапка и логотип с веткой повторяют опубликованную систему; нижней навигационной панели нет. На desktop сводка справа, на mobile — раскрываемый компактный блок перед шагом. Мастер: три шага, салон: четыре. Имя, контакт и необязательный комментарий остаются; новые обязательные поля не добавляются. Часовой пояс и реальная цена берутся из данных исполнителя.

В макетах круглые инициалы показывают fallback при отсутствии фотографии. В реализации использовать реальные круглые фото/логотипы из API. Имена, адрес, цены и календарные окна здесь иллюстративные и не отправляются в production.

Функция добавления в кабинет условная, только для вошедшего клиента. После claim существующий API закрывает гостевую ссылку — интерфейс переводит клиента в «Моё». Активная запись отменяется через компактный dialog. Перенос визита будет отдельным этапом U-08C, поэтому в этом макете не добавлена кнопка с отсутствующим гостевым API.
