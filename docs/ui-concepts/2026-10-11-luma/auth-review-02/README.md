# Вход и регистрация — утверждённый вариант с крупным выбором роли

11 октября 2026, Asia/Novosibirsk. Пользователь принял показанный экран с уточнением: увеличить шрифт кнопок выбора типа аккаунта. Это review-02; исходные PNG review-01 сохранены.

- [Вход desktop](login-1440.png), [mobile](login-390.png).
- [Регистрация desktop](register-1440.png), [mobile](register-390.png).
- [Исходный HTML](index.html). Реализация использует ту же компоновку и настоящие данные/API, не HTML-заглушку.
- «Я клиент», «Я мастер», «Мы салон»: Manrope **16 px / 700**, контрастный текст, кнопки не ниже 48 px. Три существующих серверных типа аккаунта сохранены; отдельная роль сотрудника не добавляется.
- Яндекс, Telegram, VK ID — недоступные кнопки с «Скоро». Логин/пароль работают до подключения внешних способов и согласования миграции существующих аккаунтов.
- Код восстановления после регистрации сохраняется. Приглашение в существующий салон продолжает работать, с сохранением безопасного возврата.

Код: `frontend/src/pages/Auth.tsx`, `frontend/src/auth-reference.css`, общие `PublicHeader.tsx` и `Brand.tsx`. Проверочные снимки реального UI и выпуск — в [отчёте](../../../RELEASE_20261011_NAVIGATION_AUTH_REFERENCE.md). Полный кабинет клиента U-08C этим этапом не реализован.
