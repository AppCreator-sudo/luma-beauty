## Уточнения после просмотра генерации

- Статусная строка телефона и внешние подписи — рамка презентации, не элементы сайта.
- Вместо сгенерированного «Найдено 48 результатов» выводится действующее «На странице: N»: API не обещает общее число.
- Автор работы сотрудника показывается именем человека, салон — отдельной подписью; название салона не заменяет автора. Для собственных публикаций салона сохраняется их реальная модель авторства.
- Фильтр использует настоящие направления из справочника; подписи услуг в изображении не создают новые категории.
- В деталях service-блок — информация и переход к существующей записи с услугой; отдельный новый экран услуги не создаётся. Цена/длительность только из данных.
- Фото основной галереи показывается целиком; превью допускает кадрирование без растяжения. Рейтинг мастера, обучение, окно и другие условные сведения выводятся только когда есть соответствующие данные, даже если они не попали в пример карточки.
- На уточнённой desktop-доске генерация пропустила строку поиска каталога и кнопку «На карте»: они обязательны над фильтрами, как в mobile и спецификации. Лупа шапки их не заменяет. На всех экранах сохраняется одинаковый логотип Luma Beauty; подписи 01/02/03 и крупная ветка возле них — обозначения презентации, не новая шапка. Высота фото деталей определяется исходным соотношением сторон, а не горизонтальным прямоугольником примера.
