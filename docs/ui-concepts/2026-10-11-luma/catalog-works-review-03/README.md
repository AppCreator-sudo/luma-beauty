## Утверждённое поведение и точность данных

Оба раздела: «Показать ещё» добавляет порцию вниз, не заменяет карточки и не запускается автоматически при скролле. Сохраняется место при возврате. «Показано: N» — уже загруженные уникальные карточки, не общее число базы. Кнопка недоступна при загрузке, ошибка повторяет ту же порцию без потери показанного, конец выдачи убирает кнопку. Смена фильтра начинает новую выдачу.

Каталог: 3 desktop / 1 mobile, поисковая строка и карта остаются. Длительность зависит от выбранного дня; справочник направлений настоящий. Отдельных сотрудников в общем каталоге нет. Рейтинг мастера, ближайшее время, обучение и совпавший сотрудник показаны только при реальных данных; у салона нет общего рейтинга/сердца до F-07. Фото, люди, услуги и цены на изображениях иллюстративные и не переносятся в production.

«Вдохновение»: 4 desktop / 2 mobile, фото сохраняют пропорции; карточки не выравниваются в одинаковые горизонтальные ряды. Под каждым фото — короткая подпись и реальный автор; салон для сотрудника отдельной строкой. Число фото — только если их несколько. Сохранение работы остаётся в деталях, как в текущей модели. Ряд с «Индивидуальный мастер» в mobile-иллюстрации не добавляет новое обязательное поле — использовать реальные город/салон автора. Нет ограничений «ровно два ряда» при masonry.
