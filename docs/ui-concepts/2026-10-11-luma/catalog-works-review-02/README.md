## Состав предложения

Каталог: 3 колонки desktop / 1 mobile, равноправные компактные карточки самостоятельного мастера и салона; поиск, направление/свободный день/длительность и переход к существующей карте. «Вдохновение»: 4 колонки desktop / 2 mobile, умеренная высота превью, подпись, человек-автор и салон при наличии. Детали: галерея целиком, миниатюры, автор, связанная услуга, запись/сохранение. Сохраняется текущая постраничная навигация и возврат к позиции. Mobile использует утверждённую публичную шапку и её меню.

Рейтинг/сохранение салона остаются F-07. Не вводятся верификация, платежи, чат, сортировка или новые фильтры. Отсутствие условного поля в примере не отменяет действующую функцию: обучение, окно, совпавший сотрудник, длинные данные и пустые состояния учитываются спецификацией.

## Уточнения иллюстративных подписей

«На странице: N» — текст фактического количества карточек, не новый select числа результатов. Длительность — существующие 30/60/90/120/180 минут, активна при выбранном дне; вымышленная «Любая длительность» не добавляется. Категории берутся из справочника, даты/год из данных и времени проекта. Основное фото работы сохраняет пропорции; подписи в примерах не создают новые свойства или услуги.
