Это снимки работающего локального интерфейса с **синтетическими анкетами/адресами** и настоящими тайлами провайдеров. Одна область/выбор/карточка на каждую пару. Для OpenFreeMap в браузер временно добавлен неинтерактивный слой MapLibre GL JS 6.14.0 за существующими маркерами. Это честная проверка внешности/загрузки, **не готовая интеграция движка**. Preview использует bypassCSP только в своём Playwright-контексте; CSP приложения не менялась. Ошибок загрузки OpenFreeMap на обоих размерах 0; атрибуция сохранена.

Стиль: Positron, кремовые здания/земля, приглушённые парки/вода/дороги, русские подписи при наличии данных; сторонние POI/transport/housenumber скрываются, если соответствующие слои присутствуют. Окончательная читаемость адресов и производительность требуют проверки после выбора. Исходные утверждённые PNG не менялись.

По просьбе пользователя добавлен **Яндекс** как исследованный вариант: [способы подключения, точки, ключи, тарифы и ограничения](../../../V2_MAP_PROVIDER_OPTIONS.md). Для него нет снимка Luma без ключа проекта. Можно сохранить Leaflet с официальным Tiles API либо перейти на JS API 3 ради векторного стиля. Ни один вариант пока не внедрён.

Production не менялся. Для воспроизведения сравнения используется [capture.mjs](capture.mjs) из корня checkout: сначала создать отдельную тестовую базу через tests/fixtures/map-reference-server.mjs, записав manifest в .cache/map-provider-comparison-20261014; после frontend build запустить node docs/ui-concepts/2026-10-14-luma/map-provider-review-01/capture.mjs. Нужны Chrome и сеть к официальному стилю/тайлам и pinned MapLibre CDN. Нельзя направлять fixture на production DATA_DIR.
