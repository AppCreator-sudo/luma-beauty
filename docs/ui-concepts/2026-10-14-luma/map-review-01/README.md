## Утверждённые решения

1. Вместо неподдерживаемых селекторов города/дня — существующий поиск «Город, мастер или салон», полный справочник направлений и «Есть время в ближайший час». День не добавляем в API в рамках UI. В списке не показываем отсутствующие в map API рейтинг, километры и цену «от»; цена реальной услуги появляется после выбора места.
2. Mobile: шапка, поиск/кнопка фильтров, переключатель «Список / Карта» над содержимым. Оба вида относятся к одной области; при переключении сохраняются фильтры, карта, список и выбор. Карта использует оставшуюся высоту экрана. Карточка снизу внутри карты, точка видна над ней; на коротком экране карточка прокручивается. Это не нижняя навигация сайта.
3. Desktop: две колонки по эталону, выбранная карточка сверху слева на карте. Действующие ближайшие время/услуга/цена/длительность/сотрудник добавлены внутрь неё. Нет окна за семь дней — «Посмотреть расписание»; ошибка карточки — «Повторить» и страница. У списков есть loading/empty/error/group/дозагрузка без автоматической бесконечной ленты. Отказ геолокации не блокирует ручной поиск.

Обычное открытие меню в прототипе только обозначает наличие общей навигации. В реализации повторно использовать существующий MenuOverlay/его анимацию и историю; не переносить облегчённое демонстрационное меню из prototype.js.

## Состояния прототипа

Параметр `?state=`: `selected`, `master`, `list`, `filters`, `group`, `empty`, `error`, `loading`, `details-loading`, `details-error`, `no-time`, `geo-denied`, `tiles-error`, `more-error`, `long`. `view=list` позволяет открыть список. Статические сценарии не имитируют ответ настоящего API и не проверяют его.

## Проверки и воспроизведение

[capture.mjs](capture.mjs) запускается `node docs/ui-concepts/2026-10-14-luma/map-review-01/capture.mjs` из корня. Нужен установленный Chrome. [prototype-check.json](prototype-check.json) фиксирует проверки изолированного макета: 16 сочетаний состояния/экрана, 1440×900, 390×844, 320×568 и 800×600; отсутствие горизонтального переполнения, высота видимых кнопок от 44 px, переключение вида, применение фильтров, закрытие карточки, reduced-motion и ошибки JavaScript. Это **не** проверка приложения, API, сохранения истории или production. Скриншоты визуально просмотрены отдельно; frontend/root build не требуется, исходный код приложения не менялся.

Хеши неизменного источника и новых артефактов — в [reference-manifest.json](reference-manifest.json). Решение пользователя получено 14.10.2026; U-09-02 проверена локально, её отчёт доступен выше.
