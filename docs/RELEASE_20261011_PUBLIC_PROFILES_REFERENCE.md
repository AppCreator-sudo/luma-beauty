## Интерфейс и сохранённые функции

Публичные страницы `/v2/m/:slug` и `/v2/s/:slug` перенесены по desktop-эталонам 10 октября и утверждённым mobile-уточнениям 11 октября. Широкие обложки, круглые аватары, вкладки, компактная команда и галерея в четыре desktop-/две mobile-колонки. Логотип салона центрирован; окно мастера на телефоне находится перед галереей.

Ближайшие окна берутся из расписания и занятости; переход передаёт услугу, исполнителя и время. Подробности работы и сама форма записи сохраняют прежний UI до U-07/U-08. ## Стаж и база

Добавлен необязательный стаж мастера/сотрудника в годах и месяцах. Кабинеты сохраняют общее количество месяцев, показывают отдельные поля лет 0…99 / месяцев 0…11. Неправильный ввод не преобразуется автоматически и блокирует сохранение, в том числе в форме сотрудника с noValidate. Старый клиент без поля сохраняет прежнее значение; пустое поле очищает стаж. Backend допускает только целое 0…1199 либо NULL.

Добавлена nullable-колонка `profiles.experience_months` с CHECK. Для существующих профилей стаж не придумывается. Перед выпуском сделан согласованный SQLite snapshot через backup API и репетиция миграции на копии: прежние строки профилей совпадают, новые значения пусты, integrity_check ok. После запуска повторно проверены колонка и целостность рабочей базы. Пользовательские uploads и существующие записи сохранены; тестовые базы/пользователи не отправлялись на сервер.
