# Кабинет мастера — сверка и согласование эталона

Согласования и проверки этапа [U-03](tasks/U-03.md) сохранены ниже; [отчёт выпуска](RELEASE_20261010_CABINET_REFERENCE.md) подтверждает его результат. Актуальную работу выбирать по [карточкам задач](tasks/README.md), а не по последовательности этого обследования. Проверки здесь относятся к указанному выпуску, не к новой проверке рабочего сервера.

10 октября 2026 года. Обзор и кабинетная навигация опубликованы в `20261010-v2-cabinet-reference`.

## Утверждённые решения

- Шапка и логотип Luma / BEAUTY с золотистой ветвью следуют эталону кабинета. Главная сохраняет опубликованную композицию.
- Уточнённые [desktop](ui-concepts/2026-10-10-luma/cabinet-review-01/desktop.png) и [mobile](ui-concepts/2026-10-10-luma/cabinet-review-01/mobile.png) утверждены. Подтверждение заявки бордовое на обоих экранах.
- Отдельные блоки заявок и подготовки страницы, круглые инициалы клиентов утверждены. Будущие pending не скрываются фильтром дня.
- Лупа открывает существующий поиск каталога с фокусом в поле. Поделиться — в меню профиля. Контакт, заметки, отмена — в подробностях записи.
- Публикация, график, уведомления, безопасность и выход сохранены в настройках.

## Сохранение функций

| Функция | Реализация |
| --- | --- |
| Семь дней / записи дня | Реальные `/appointments`, фильтрация в часовом поясе графика |
| Заявки | Все собственные pending, подтверждение и отмена с существующим API |
| Завершение / контакт / заметки | Завершение в строке и подробностях; детали открываются в нативном dialog |
| Подготовка | Услуга, сохранённый график, публикация; исчезает после выполнения |
| Ближайшее окно | Первый будущий слот `/studio.availability`, без условного времени из макета |
| Создание записи | Существующий `/calendar?new=1` и пошаговая форма |
| Публичная страница / share | Текущий `/m/:slug`, системное share либо clipboard |
| Услуги, работы, оформление, настройки | Существующие формы и права сохранены в новой оболочке |
| Без профиля / guest / client / salon | Существующие первичная настройка и переходы по ролям сохранены |

Изображения, даты и числа из генераций не переносились в production. При отсутствии работ — нейтральная пиктограмма, при отсутствии аватара — круглый инициал. Этот выпуск относится к обзору и навигации мастера. Календарь позднее завершён в [U-04](tasks/U-04.md); оставшиеся профессиональные формы учитываются отдельно в [инвентаризации U-10-01](tasks/U-10-01.md) и её карточках, без повторного переноса обзора.

## Проверка

1586, 1366, 1024, 800, 390, 320 px без горизонтального переполнения. Подробности/Escape, подтверждение, завершение, отмена, сохранение услуги/графика/публикации после reload, открытие поискового поля и новая запись проверены на отдельной локальной SQLite. Ошибок страницы нет. Исходные пять PNG сверены SHA256 и не менялись. Физический телефон и авторизованный production-аккаунт в этой проверке не использовались.

Сборка успешна. Production: статический выпуск, опубликованные entry assets сверены, HTTP 200 публичных маршрутов, health ok, service active. Сервер, рабочая база и пользовательские файлы не менялись. Отчёт: [RELEASE_20261010_CABINET_REFERENCE.md](RELEASE_20261010_CABINET_REFERENCE.md).
