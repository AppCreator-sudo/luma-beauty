# Работы команды салона во «Вдохновении»

Опубликовано 7 октября 2026 в 19:17:38 по Новосибирску (12:17:38 UTC). Серверный выпуск `20261007-v2-inspiration-visibility`; frontend `20261007-v2-home-alignment` сохранён.

## Изменение

Общая лента раньше требовала публикацию отдельной личной страницы сотрудника. Теперь `/api/inspiration` использует общую с полной работой проверку: салон опубликован, владелец существует, сотрудник активен и показ включён, сотрудник не демонстрационный. Публикация старой личной страницы не обходит скрытие сотрудника или салона. Работы индивидуальных мастеров сохраняют прежние правила публикации.

Лента передаёт `performer_id`, `salon_id`, `salon_slug`, `salon_name`: существующий интерфейс ведёт к автору внутри салона, без отдельной карточки в каталоге. Для сотрудника город берётся у салона, включая фильтр города. Русские буквы приводятся к регистру через локальную SQLite-функцию: встроенный `lower()` обрабатывал только ASCII. Связанная услуга проверяется также по автору. Галереи, сохранение и курсорная пагинация по двенадцать записей сохранены; интерфейс продолжает показывать восемь превью на странице.

Скрытие ограничивает новые публичные ответы и открытие работы. Запись портфолио сохраняется и снова доступна после включения показа. Уже загруженные превью могут оставаться в существующем клиентском кэше до 60 секунд; полная работа всегда повторно проверяется сервером. Отдельная лента подписок `/api/feed` этим выпуском не менялась.

Пагинация `12 + 2` при одинаковом времени не теряет и не повторяет работы; неверный курсор отклоняется. Неопубликованная индивидуальная страница сохраняет приватность.
