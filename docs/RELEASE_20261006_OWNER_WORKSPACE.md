# Кабинет владельца салона и отдельный показ мастера — 6 октября 2026

Состояние: опубликовано в составе `20261006-v2-public-identities`; отдельный релиз owner-workspace не выпускался. После подготовки владелец попросил сначала публичные UI-концепты: новый этап выполнен, уже готовые скрытие/обзор владельца включены вместе с ним. Итоговый выпуск: [RELEASE_20261006_PUBLIC_IDENTITIES.md](RELEASE_20261006_PUBLIC_IDENTITIES.md).

Кабинет владельца стал компактнее: шапка с брендом салона, общий календарь, выбор сотрудника со статусом показа, формы записей и услуг рядом с основной областью на десктопе. Мобильные ограничения ширины сохранены; полная адаптация по концептам остаётся отдельным этапом.

Над вкладками выбранного сотрудника есть отдельные «Скрыть от клиентов» / «Показать клиентам». Скрытый мастер исчезает со страницы салона, из групп услуг и новой онлайн-записи, включая отправку из ранее открытой формы. Его карточка в кабинете, график, услуги, текущие записи, история и личный доступ сохраняются; архивирование не вызывается. Если скрыты все сотрудники, опубликованная страница салона остаётся существовать с пустой командой и услугами. Для включения показа по прежним правилам нужны услуга и сохранённый график; при скрытом салоне кабинет объясняет, что мастер появится после публикации самого салона.

Минимальное серверное изменение: `PATCH /api/performers/:id/visibility` с обязательным булевым `visible`, доступный только владельцу. Меняется только существующий `performers.bookable`, без миграции. Новая форма сохранения карточки не отправляет видимость; отдельная кнопка не перезаписывает поля карточки. Старый полный PUT оставлен совместимым. Самостоятельная личная практика сотрудника имеет собственную видимость.

Проверки: одна финальная сборка frontend; целевой `tests/salon-public.test.mjs` прошёл с проверками прав, строгого boolean, скрытия/возврата, закрытия старой формы записи, сохранности профиля/услуг/графика/истории/доступа и сохранения карточки без изменения показа. Шесть коротких браузерных проверок владельца прошли на изолированных вымышленных данных: календарь команды, реальное сохранение ручной записи, отказ сохранения видимости без потери ввода, скрытие при несохранённой карточке, повторное открытие/возврат и ширины 390/320 px без переполнения с кнопкой 44 px. Исключений браузера нет. Исправлено сравнение прототипа SQLite-строки в добавленном тесте; итоговый прогон прошёл.

Исходный серверный файл подтверждён: после удаления нового обработчика локальный SHA256 совпадает с рабочим сервером. Пакет содержит только frontend, PWA и `lib/workspaces.mjs`; аккаунты, тестовые данные, фотографии и окружение в него не входят. Новый выпуск копирует прежний сервер с его зависимостями и старыми assets, сохраняет `/opt/atelie/shared`, переключает ссылку с восстановлением прежнего выпуска при сбое. Данные и схема не меняются.

Публичный первый блок по концептам опубликован тем же выпуском. По последнему указанию следующий этап — дальнейшие кабинеты от этого визуального характера. Адреса без DaData, замена карты, PostgreSQL/PostGIS и чат остаются последующими этапами.
