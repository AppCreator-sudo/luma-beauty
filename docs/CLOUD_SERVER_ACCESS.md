# Полный перенос Luma Beauty в облачную разработку

14.10.2026 пользователь повторно и явно поручил загрузить в закрытый GitHub все необходимые файлы, включая существующие секреты и полную рабочую базу. Предложение новой SSH-учётной записи/привилегированного помощника отменено. Серверные права не меняются.

## Состав

- `deploy/cloud-transfer/source-data/`: полный исходный снимок SQLite, фото и VAPID. Все данные исходной копии сохранены.
- `deploy/cloud-transfer/server-secrets/`: существующий SSH-файл, серверный env, локальная конфигурация адреса, известный ключ хоста, конфигурация подключения и ключ прежнего зашифрованного пакета.
- [Отчёт и контрольные суммы](../deploy/cloud-transfer/manifest.json).
- [Импорт](../scripts/cloud-private.mjs), [установка среды](../scripts/cloud-setup.sh), [подключение](../scripts/cloud-server.py).

По прямому запросу пользователя эти файлы входят в private репозиторий. Реквизиты не печатать в чат/логи. Новые файлы не меняют код/UI приложения.

## Создание среды

Выбрать private AppCreator-sudo/luma-beauty в Codex Cloud. Готовый запрос:

```text
Настрой Luma Beauty из этого репозитория. Прочитай AGENTS.md и checkpoint.
Выполни bash scripts/cloud-setup.sh: зависимости, сборка и импорт уже включены.
Запускай npm start с NODE_ENV=development,
DATA_DIR=$PWD/.local-data/cloud-dev, PORT=3100 и APP_ORIGIN равным preview URL.
Не подключай production.env к локальному приложению.
Проверь /api/health и /v2/. Сохрани и опубликуй среду.
Правки кода и новый выпуск сейчас не нужны.
```

Ключи вручную переносить в vault для этого варианта не требуется. setup импортирует полную исходную копию в `.local-data/cloud-source`, а запускаемую копию — в `.local-data/cloud-dev`. Исходный snapshot не меняется. В рабочей копии удаляются только действующие сеансы/push-подписки и не используется production VAPID, чтобы тесты не отправляли уведомления настоящим клиентам. Бизнес-данные/фото сохраняются.

## Сервер

Используется существующий доступ из переданного SSH-файла; новый luma-codex не нужен. Локальный код подключается со сверкой известного ключа хоста:

```sh
node scripts/cloud-server.mjs status
node scripts/cloud-server.mjs run 'КОМАНДА ДЛЯ LUMA BEAUTY'
```

Не выводить значения env или пароль. Работать только с Luma Beauty. Выпуск: сохранить shared/backup, проверить совместимость и действующее разрешение, затем publish/health по проектному плану.

SSH из реальной cloud-среды ещё не проверен: его доступность зависит от сети среды. Это ограничение подключения, а не отсутствие переданных реквизитов. Сама среда ещё не создана.
