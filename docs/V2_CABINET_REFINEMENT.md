## Согласованное поведение

1. Публикации: явные разделы «Публикации салона» и «Работы мастеров»; сотрудник выбирается до открытия формы. В форме автор фиксирован, второй выбор автора отсутствует. При редактировании обычный текст автора вместо disabled select; перенос между авторами не нужен. Внутри карточки сотрудника только его работы, включая пустое состояние.
2. Ближайшее окно: кнопки времени меняют выделение на месте. «Выбрать это время» продолжает с выбранными услугой/датой/временем. Самостоятельный мастер → контакт; салон → доступный именно в это время мастер или «Любой свободный» → контакт. Повторный выбор времени не нужен. «Или выбрать своё время» открывает обычный календарь. Устаревшее окно объясняется; контакт и совместимые выборы сохраняются.
3. График: режим по выбранным дням недели и сменный цикл с пресетами 2/2, 3/3 и произвольными числом рабочих/выходных, датой начала цикла и часами. Отдельные даты могут менять рабочий/выходной и часы. Предпросмотр календаря. Один расчёт для кабинета, публичных окон, карты, записи и переноса; существующие визиты не удаляются.
4. Медиа: управление карандашом/удалением непосредственно на аватаре и обложке вместо больших upload-форм. Аватар — перемещаемая круглая область с изменением размера, preview, сохранить/отмена. Обложка — предпросмотр; удаление возвращает стандартную палитру. Неудачная замена сохраняет старый файл; серверные проверки и права обязательны. Удаление фото сотрудника сопровождается объяснением существующего отключения записи.
5. Компактность: связанные поля 12–16 px, label/control 6–8 px, секции 20–24 px; панели 16 px mobile / 20–24 px desktop, действия от 44 px, основной текст 14–16 px, mobile input 16 px. Группировка, компактные строки услуг и действия публикации в ряд. Общий аудит всех реально существующих маршрутов/ролей/состояний, а не закрытие всего UI по нескольким формам. Полноэкранная главная и утверждённые сетки публичных работ сохраняются.
