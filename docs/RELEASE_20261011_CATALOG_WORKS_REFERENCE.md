## Согласованный внешний вид и поведение

Источник — [утверждённый review-03](ui-concepts/2026-10-11-luma/catalog-works-review-03/README.md), [спецификация](V2_CATALOG_WORKS_REFERENCE_AUDIT.md). Исходные PNG сохранены без изменений. Детали работы используют desktop review-03 и четвёртый экран mobile review-02.

Каталог: 3 колонки desktop / 1 mobile; самостоятельные мастера и салоны имеют равный визуальный статус, сотрудников отдельно не выводим. Сохранены поиск имени/услуги/города, направление, свободный день, длительность, реальные цены, ближайшее окно, команда/совпадение сотрудника, обучение и условные состояния продвижения. Рейтинг салона не выдуман.

«Вдохновение»: masonry с пропорциональными фото разной высоты, 4 колонки desktop / 2 mobile, реальные авторы и ссылка на сотрудника внутри салона. Размеры новых фото определяются до размещения порции, чтобы уже просмотренные карточки не смещались.

В обоих разделах — единое **«Показать ещё»**, ручная догрузка с защитой от двойного нажатия и дублей. Ошибка следующей порции сохраняет карточки и даёт повтор. Изменение фильтра сбрасывает выдачу и игнорирует запоздалый ответ предыдущего запроса. Возврат из карточки восстанавливает загруженные порции и позицию; после истечения кэша порции обновляются по свежим курсорам. Старые cursor/offset-ссылки остаются читаемыми.

Детали работы: фото целиком, миниатюры и выбор фото, название/автор/реальная связанная услуга, запись и сохранение. Ошибка сохранения показана в странице. Для гостя сохранение ведёт на вход с адресом возврата. Для сотрудника сохраняются выбранные салон, мастер и услуга. У самостоятельного мастера заявка сохраняет `reference_work_id`; салонная запись сохраняет действующее поведение API, без добавления нового поля в этом UI-выпуске.

Шапка и логотип — существующий компонент U-06. Лупа фокусирует поиск каталога; мобильное меню заменяет прежнюю нижнюю навигацию только на этих публичных маршрутах. Главная, карта, кабинеты и последовательность записи сохраняются.
