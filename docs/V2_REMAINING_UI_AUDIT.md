## Метод и пределы доказательств

- **Код** — заново прочитаны router/Shell, ветки ролей и состояния затронутых страниц/общих компонентов. Символ компонента в матрице указывает действующий экспорт, а не предполагаемый отдельный файл.
- **Ранее проверено** — использованы датированные локальные/публичные отчёты, JSON/TAP и снимки. Это доказательства перечисленных сценариев в дату прежней проверки; они не превращены в новый browser PASS.
- **Визуальная сверка** — открыты desktop/mobile PNG cabinet-review-01, salon-cabinet-review-01, auth-review-02, последний прайс salon-simplicity и фактические снимки первичных форм, оформления мастера, опубликованного прайса. Исходники не перерисовывались.
- **Новая локальная проверка** — установленный `react-router-dom.matchRoutes` принимает пять адресов с завершающим `/`, которые не проходят точные сравнения Shell. Для удаления и сбоя `/api/me` вывод основан на обработчиках кода; воспроизведение браузером включено в BUG-карточки.
- Новый запуск приложения, fault injection, save/reload, выпуск и физический телефон в этом документарном аудите **не выполнялись**. Проверка документов, полноты маршрутов/зависимостей и сохранности эталонов — [отчёт](ui-checks/2026-10-15-ui-residual-audit/README.md).

## Конкретные предложения для отсутствующих состояний — ещё не согласованы

1. **Восстановление U-10-08.** На принятом экране R6 под кнопкой входа — текстовое действие «Забыли пароль?». В той же карточке desktop (правая колонка) и mobile (одна колонка) поля «Логин», «Код восстановления», «Новый пароль», показать пароль; «Назад ко входу» и бордовая основная кнопка. После успеха — существующий паттерн одноразового нового кода и «Я сохранил код», переход по фактической роли/безопасному next. Для вошедших профессиональных аккаунтов ссылка из `/access`. Переиспользовать API `/auth/recover` и логику ClientRecovery, без смены правил аккаунта и без вывода кодов в отчёт. До решения пользователя этот UI не добавлять.

3. **Старый staff U-10-09.** Сохранить свои календарь/услуги/график/работы/оформление, общую зелёную шапку R10, подпись салона, круглое фото, компактные вкладки с переносом строк на 320 px. Новая 404, возвращение gutter/нижней панели, изменение структуры прайса, новые приглашения, социальный вход, смена карты/БД/адресного провайдера и оплаты в предложения не входят. Единый [UI-журнал](V2_UI_REFERENCE_IMPLEMENTATION.md) остаётся источником приоритета утверждённых макетов.
