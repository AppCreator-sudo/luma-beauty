# U-10-06 / BUG-020 — профессиональная кнопка уведомлений

Локальная проверка в Chrome на отдельной синтетической SQLite. ServiceWorker, Notification и PushManager эмулируются; разрешение ОС и фактическая доставка на телефон не проверяются (F-08-02). Вызовы сохранения подписки проходят через настоящий локальный API.

## Исходные дефекты

[Baseline](baseline.json): кнопка остаётся busy после 10 секунд незавершённого serviceWorker.ready; отсутствие Notification API выводит техническую ошибку requestPermission. Три исходных проверки, включая остановку сервера и integrity/FK, пройдены.

## Исправление

[AccountTools.tsx](../../../frontend/src/components/AccountTools.tsx): явная проверка HTTPS и API; ожидание службы ограничено 8 секундами, таймер очищается; понятные сообщения об отказе разрешения, ключе и ошибках сети/браузера. Во время операции кнопка показывает «Включаем…», повтор защищён синхронным флагом. Существующая подписка используется повторно, успех появляется только после подтверждения POST. Композиция, серверные роли и схема базы сохранены.

## Матрица приёмки

Мастер и владелец салона × 1440/390/320 × 14 сценариев: PushManager отсутствует, HTTPS отсутствует, Notification отсутствует, denied, отмена разрешения, GET key 503, испорченный ключ, ошибка сети, ошибка браузерной подписки, POST subscribe 503, serviceWorker.ready не завершается, ready отклоняется, существующая подписка и busy/повтор. Для восстановимых отказов проверяется успешный повтор. Проверяются русский текст, overflow, кнопка от 44 px, отсутствие нижней навигации и необработанных JS-ошибок.

Настройки салона открываются через меню профиля. У каждого тестового аккаунта независимые подписки; регистрация не обходит лимиты. Неизменяемые бизнес-GET ответы повторно используются из фактического локального API. Frontend копируется в test-results, чтобы параллельные сборки проекта не меняли проверяемые файлы.

Скрипт: [verify-professional-push.mjs](../../../scripts/verify-professional-push.mjs). Итог: **87/87 PASS**, JS errors 0, overflow 0, кнопка от 44 px. 66 уникальных endpoint сохранены, повторные POST не создают дублей; после остановки fixture integrity/FK PASS. Обе сборки PASS, 163 исходных PNG сохранены. Все 10 снимков просмотрены.
