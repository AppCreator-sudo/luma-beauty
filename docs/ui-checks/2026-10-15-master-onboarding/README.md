## Проверенный путь

На каждой ширине 1440×1000, 390×844, 320×844:

1. Гостевой `/studio`, регистрация мастера через действующий UI и экран сохранения кода; `/calendar` без профиля возвращает к первой форме.
2. Неподтверждённый/неверный дом не позволяет создать профиль. Точный дом проверяется при сохранении. Отказ провайдера сохраняет введённые поля и прежний подтверждённый адресный черновик; reload восстанавливает подтверждённый адрес.
3. Создаётся скрытый профиль с именем/slug/двумя направлениями/описанием/стажем 30 месяцев. Гость получает 404; график ещё не считается сохранённым.
4. Через форму добавлена первая услуга: направление, 2500 ₽, 60 мин; reload сохраняет значения. Публикация без явно сохранённого графика отклоняется сервером и недоступна в UI.
5. Недельный график сохранён с UTC+7 и часами 10:00–19:00. Открытие страницы → reload → публичные услуги/окна в правильном времени → переход в клиентский календарь записи.
6. Скрытие → reload → гостевой 404. Затем сохранённый цикл 2/2 → открытие → reload → публичная страница. Обе модели графика работают.

Отдельно проверены клиент без workspace (`/studio` объясняет роль, `/calendar` → `/me`, PUT профиля 403), клиент с salon workspace и salon account (`/studio`/`/calendar` → `/salon`). Старые связанные staff — отдельная U-10-09.

Серверные тесты дополнительно покрывают график с исключением/только отдельной рабочей датой, пустой/несохранённый график, отсутствие услуги/профиля, чужие роли/Origin/попытку подмены user_id, сохранность профиля/визита, адресные ошибки и конкурентные сохранения.
