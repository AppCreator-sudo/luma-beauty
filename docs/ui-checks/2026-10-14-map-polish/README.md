# U-09-03 / U-09-05 — финальная доводка текущей карты

**Проверено локально 14.10.2026**, Asia/Novosibirsk. Production не менялся. [Браузерный отчёт](browser-report.json), [принятый review](../../ui-concepts/2026-10-14-luma/map-review-01/README.md), [задача](../../tasks/U-09-05.md).

## Реальный результат

- Общая шапка/ветка Luma, кремовые панели, бордовая запись, круглые фото; без старой нижней навигации на /map.
- Собственные SVG-капли с острым кончиком вместо повёрнутых овалов. Мастер — зелёный/ножницы, салон — бордовый/лепестки, выбранная точка с контуром. Группы остаются круглыми со счётчиком.
- Реальный средний рейтинг и число отзывов у мастера/салона; без отзывов — «Пока без оценок». Один клиентский отзыв на завершённый визит, 1–5. Салон определяется сохранённым местом визита, не нынешним составом команды; личные визиты сотрудника не становятся отзывами салона. Один helper используется в map API и существующих агрегатах каталога/мастера. Отдельная полноценная страница отзывов/сохранение салона не реализованы.
- Карточка не закрывает выбранную точку, управление масштабом и атрибуцию. При zoom выбранная точка возвращается в свободную область. Исправлен быстрый zoom сразу после выбора: старый отложенный capture больше не читает промежуточные bounds анимации и не вызывает ложное «Здесь пока никого нет».
- Сохранены поиск/направление/ближайший час, карта/список, группы, ручная догрузка, история, реальные профиль/запись/услуга/цена/длительность и сотрудник салона.
