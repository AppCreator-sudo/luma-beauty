# U-08C — проверка рабочей реализации кабинета клиента

11 октября 2026, Asia/Novosibirsk. **Проверено локально и опубликовано 11.10.2026 23:15:02 Новосибирск.** Это снимки реализации с отдельной тестовой базы на 127.0.0.1:3214, а не макеты и не production-данные. Эталоны review-01/review-02 неизменны.

- [Layout](layout.json): семь разделов × 1440/390/320 px, 21 проверка без горизонтального переполнения, нижней панели и ошибок страницы.
- [Функции](functional.json): запись/claim, отзыв и повторы, inbox/read, профиль/приватное фото/save/reload, экспорт, предзаполнение заявки, общее меню.
- [Дополнительная приёмка](acceptance.json): фактическое принятие переноса владельцем салона, приватная проекция двух API записей, новый аккаунт, 113 уведомлений с cursor без дублей, пароль/завершение других сеансов/восстановление и смена кода.
- [Крайние состояния](final-edges.json): ширины 800/801, короткий экран 320×568, reduced-motion, Back, ошибка загрузки/повтор, предупреждение о несохранённом профиле, кнопки от 44 px.
- [Другой день](cross-day.json): календари мастера/салона переходят на принятую новую дату; город профиля заполняет существующий поиск, очистка и явный запрос работают.
- [Возврат](return.json): отправленная форма не открывается повторно при Back из деталей — возвращается предыдущая страница списка.

Отчёты functional/acceptance содержат отметки продолжения ранее выполненных проверок. Отдельно в локальных журналах проверены отказ/отзыв/отмена и реальная коллизия: новое окно до принятия не резервируется; при занятом окне исходная запись и pending-запрос сохраняются, повтор после освобождения окна успешен. Эти сценарии также покрыты целевыми серверными тестами. Они не выдаются за повторный полный прогон.

Frontend build и корневая проверка прошли; 10 целевых серверных тестов — PASS. React-проверка: хуки до условных выходов, независимые запросы параллельно, отдельный модуль профессиональных настроек, cleanup обработчиков, защита повторной отправки, личные черновики в памяти без URL/history/storage.
