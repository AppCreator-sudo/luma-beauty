# Простой кабинет салона — локальная проверка 15.10.2026

Реальные собранные страницы приложения, отдельная синтетическая SQLite и localhost. Это не публикация и не текущие production-данные. [Контракт](../../V2_SALON_SIMPLICITY_PROPOSAL.md), [план выпуска](../../SALON_SIMPLICITY_RELEASE_PLAN.md).

## Проверено

- [31 пункт браузера/API](report.json): создание услуги по направлению и назначение; автоматические направления сотрудника; save/reload; индивидуальные условия и список затронутых мастеров; редактирование только данных; график 2/2 и копирование; добавление нового готового мастера с фото; изолированные работы автора; переходы с сохранением контекста и browser Back; предупреждение о несохранённой форме; конфликт версии сохраняет ввод и предлагает обновление прайса.
- Ближайшее окно: кнопка времени только выбирает, подтверждение ведёт к мастеру и контакту без повторного календаря; конкретные цена/длительность видны до отправки. Реальная отправка тестовой гостевой заявки создала визит к выбранному исполнителю с его ценой/90 минутами. Старый URL услуги открывает актуальный выбор. Архив прекращает новые записи без удаления service rows.
- 1440/390/320 px: нет горизонтального overflow и старой нижней навигации. Native select без постоянной рамки, радиус 10 px, высота от 44 px; keyboard focus 2 px. Сохранены стандартные шрифты, цвета и логотип. JS errors0.
- [Миграция полной прежней синтетической базы](migration.json): **42 таблицы / 901 строка сохранены дословно**, 4 прежних предложения → 1 точная группа; backup закрыт, FK/integrity чистые; повторный запуск идемпотентен. Исходная БД открывалась read-only; uploads не менялись. Свежий production preflight остаётся частью будущего выпуска.
- `tests/salon-catalog.test.mjs`: **5/5 PASS** — неизменность старых IDs/строк, разные старые условия, overrides, CAS, снятие/возврат назначения, FK, owner rights, фактическая длительность, изменение показанной цены, полный rollback при сбое, архивный/чужой исполнитель.
- Смежные целевые проверки: appointment editing, client cabinet, guest bookings, service directions и содержательные map-viewport checks — **14 PASS**. Один прежний HTTP-fixture карты падает на подготовке staff без фото/draft, затем SQLite bind: уже зарегистрированный [BUG-002](../../tasks/BUG-002.md), воспроизведённый до этого этапа. API не ослаблялся, полный набор не объявляется зелёным.
- Итоговая проверка 2026-10-15T20:32:08+07:00: frontend build (`index-CbdQYBIA.js`), root build, документация (84 карточки / 2541 локальная ссылка / 0 ошибок) и diff PASS. Полный набор тестов не запускался.

## Повторить безопасно

`node scripts/verify-salon-simplicity.mjs` создаёт новую локальную синтетическую базу в `.cache` и временный сервер localhost:3282; в конце останавливает его. База/сессии не включены в Git. Сначала собрать frontend.

`node --test tests/salon-catalog.test.mjs` использует временные базы и localhost:3281. `node scripts/verify-salon-catalog-migration.mjs <pre-catalog.sqlite> <report.json>` открывает исходник read-only, мигрирует только отдельную `.cache`-копию и пишет отчёт без персональных строк. На реальном снимке использовать приватный путь отчёта.

Миграцию production и GitHub push в рамках этих проверок не выполняли. Исходные PNG утверждённого концепта не перезаписывались.
