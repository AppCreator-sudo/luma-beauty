## Граница и результат

Проверялся остаток [U-10-04](../../tasks/U-10-04.md) в утверждённом [wizard и сетке U-10-18](../../tasks/U-10-18.md). Проверки удаления BUG-008 повторно не запускались, новый дизайн не вводился. Исправлены воспроизведённые дефекты BUG-013/014/015/016/017; итоговый проход не подтверждает публикацию на сервере.

- Пустое портфолио открывает шаг «Услуга». Пустые услуга/фото/подпись и семь файлов дают понятную ошибку без POST. Нечитаемое фото получает настоящий 400, поля и существующие данные сохраняются; замена фото допускает продолжение.
- Обычный «Назад» и browser Back сохраняют выбранную услугу, фото и подпись. Закрытие и повторное открытие, а также полный reload несохранённого третьего шага начинают новый пустой черновик с первого шага.
- Ошибка 500 и разрыв сети показываются в форме, сохраняют черновик и позволяют повтор. Двойной синхронный submit отправляет один POST; форма и внешний переключатель блокируются на время запроса. После смены разделов незавершённый POST также блокирует повтор и снимает блокировку при отказе.
- Успешная загрузка сохраняет автора, выбранную услугу, подпись, порядок и содержимое фото. Конвертация в WebP ограничена 1600 px; reload сохраняет результат, форма сворачивается. Повтор после ошибки создаёт одну работу.
- После POST201/GET500 сообщение об успешном сохранении остаётся видимым. «Повторить обновление» выполняет только GET, повторного POST и дублей нет. Дополнительно проверен первый объект пустого портфолио после pending POST → смены разделов/remount → 201/GET500.
- На всех трёх ширинах API отклоняет чужую/отсутствующую услугу, неподдерживаемое фото, семь фото и файл больше 8 МБ без новых строк и лишних медиа. Шесть допустимых фото сохраняются с правильным автором, услугой и порядком. GET/PUT чужой скрытой работы возвращают 404, данные обоих авторов сохранены.
- Существующее встроенное создание услуги проверено на 390 px: обязательные поля → цена 0/длительность 5 → создание и автоматический выбор → публикация → reload. Направление наследуется по текущему контракту единственной категории мастера.

Отдельные целевые HTTP-тесты правил фото выполнены **18.10.2026: 9/9 PASS**: [TAP](image-policy-tests.tap), [точные границы и сохранность файлов](image-policy-after.json), [воспроизведение до исправления](image-policy-before.json).
