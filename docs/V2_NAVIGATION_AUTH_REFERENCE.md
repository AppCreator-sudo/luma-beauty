## Сохранённое поведение

- Общий `MenuOverlay` использует пружину главной: stiffness 260, damping 24, mass 0.9, раскрытие из области кнопки, размытие и последовательное появление пунктов. Кабинет остаётся зелёным, публичное меню — молочным. Это одна механика в действующей визуальной системе.
- Меню находится в верхнем слое нативного dialog, вне контейнера страницы. Фон не прокручивается; длинное меню прокручивается внутри. Закрытие восстанавливает положение страницы и фокус кнопки. Escape, клик по затемнению, Back и reduced motion поддержаны.
- `Brand.tsx` — один источник действующего Luma / BEAUTY / ветки для шапок, главной и футера. Ветка скопирована из утверждённого кабинетного логотипа.
- Реальная браузерная история запоминает разделы кабинетов, открытие меню/записи/редактора и переходы между шагами. Никакого общего перехвата свайпа по странице не добавлено. Системная кнопка, жест браузера и desktop Back используют ту же историю; на главной край экрана освобождён от обработчика смены композиции.
- Прямая ссылка возвращает к фактической предыдущей странице. Искусственное добавление обзора в историю **не согласовано и не реализовано**. Действия сохранения/удаления данных не отменяются браузерной кнопкой.
- Введённое имя/контакт и выбор записи сохраняются при возврате между шагами открытой формы. Пароли, контакты, заметки, фотографии и коды не записываются в историю. История содержит названия разделов, номера шагов и публичные/внутренние ID выбранных сущностей; API заново проверяет доступ.

## Проверенные сценарии

| Действие | Возврат |
| --- | --- |
| Обзор → услуги → портфолио | Портфолио → услуги → обзор |
| Обзор → настройки → обзор через меню | Обзор → настройки, по фактической истории |
| Открыть меню в текущем разделе | Первый Back закрывает меню, раздел остаётся |
| Перейти из открытого меню в другой раздел/страницу | Back возвращает предыдущий раздел с закрытым меню |
| Календарь → запись → редактирование | Редактирование → детали → календарь; Forward и reload сохраняют выбранную запись |
| Новая запись → клиент → время → итог | Back возвращает предыдущий шаг, затем закрывает форму; имя сохраняется между шагами |
| Гостевая запись к мастеру / в салон | Контакт → время → мастер (для салона) → услуга; введённое имя сохраняется |
| Регистрация клиента / мастера / салона | Сервер сохраняет нужный тип; выдаётся код; вход открывает соответствующий кабинет |

Проверка Chrome desktop и эмуляция mobile: 1440/390/320 px, короткий экран 320×568, изменение размера открытого меню, reduced motion, Escape/focus, отсутствие переполнения, отдельная локальная база. Физический системный жест на телефоне пользователя требует проверки на устройстве; браузерный переход Back и освобождение краевых touch-событий проверяются отдельно. Полного аудита всех бизнес-функций этот этап не заменяет.
