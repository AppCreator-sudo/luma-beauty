# Главная и компактное «Вдохновение» v2

Опубликовано 7 октября 2026, 07:19:02 UTC / 14:19:02 Новосибирск.

Frontend `20261007-v2-home-inspiration`, серверная основа `20261007-v2-salon-owner`. Резервная копия `/opt/atelie/backups/20261007-v2-home-inspiration`. Service worker `atelie-v2-shell-20261007-home-inspiration`.

## Поведение

Главная получила короткую композицию в существующих кремовом/зелёном/бордовом цветах: текст, фирменная буква и линии SVG. Анимация проигрывается один раз, заканчивается за 2,55 секунды; при уменьшении движения выключена. Сразу доступны три крупных перехода «Мастера и салоны», «Работы», «Карта». Вместо длинных подборок — компактное приглашение для мастеров и салонов с переходом в существующий кабинет владельца или начало работы. Главная больше не запрашивает списки профилей/работ; ссылки доступны независимо от их загрузки.

В «Вдохновении» по уточнению пользователя — страницы до восьми реальных работ: четыре колонки и два ряда на компьютере, две колонки на телефоне/планшете. Все фото одинакового размера, прежние большие карточки каждой седьмой работы не используются. Фотография открывает полную работу, автор ведёт к его странице. Есть краткая подпись и город/салон автора; фильтр направления закреплён при прокрутке. При меньшем числе опубликованных работ показывается фактическое количество, без заполнения копиями/моками.

Клиент показывает порции по восемь поверх существующего API, который отдаёт пакеты по двенадцать. Непрозрачный курсор сервера сохранён; следующая страница использует курсор и смещение внутри пакета, при необходимости читает следующий пакет. Недавние публичные пакеты кешируются до минуты, максимум двадцать. Переходы «Назад / Страница N / Далее», конец выдачи, ошибка/повтор, фильтр и позиция сохраняются; URL можно обновить/открыть напрямую. Без истории предыдущих курсоров доступно «К началу». Новые публикации после обновления кеша могут сдвигать динамическую выдачу.

Положение при возврате из работы восстанавливается по карточке. Ключ положения также учитывает параметры выдачи; это уточнение применено и к каталогу мастеров, чтобы разные страницы при прямом открытии не делили прежнее положение прокрутки.

## Проверки

- TypeScript/Vite прошли; небольшие корректировки после визуального просмотра собраны повторно. Прежние предупреждения о статических `hero-v2.webp` / `ornament.webp` не связаны с новым SVG.
- На изолированной локальной базе: 27 видимых работ → 8/8/8/3, 27 уникальных ID без пропусков/повторов, «Далее» отключена в конце. Прямое открытие/обновление второй страницы и переход в полную работу проверены. Возврат после окончательной сборки: сохранено 350 px, восстановлено 350 px, смещение карточки отличается на 0 px.
- Ноутбук 1366×650: четыре колонки, восемь одинаковых превью, два ряда; нижняя граница сетки около 640 px. На телефоне две колонки; горизонтального переполнения нет.
- Главная 390×844 и 320×568: кнопки не ниже 68 px; на узком телефоне границы переходов 352,7 / 427,7 / 502,7 px, нижняя навигация начинается на 506 px. `scrollWidth = clientWidth = 305`. Режим уменьшения движения подтверждён: `animationName=none`.
- После публикации: HTML/JS/CSS/PWA сверены с пакетом, health `ok`, служба `active`. В браузере проверены главная и переход в «Вдохновение», четыре колонки, загрузка рабочей фотографии. В действующей ленте одна работа; локальные fixture-записи отсутствуют. На главной нет запросов `/api/profiles` и `/api/inspiration`.

Изменены только frontend-файлы. Сервер, схема и рабочие данные сохранены; служба не перезапускалась.

## Следующая отдельная правка

При чтении API обнаружено прежнее различие правил видимости: `lib/publications.mjs:170–193` для `/api/inspiration` проверяет только `p.published=1`, а полная работа ниже использует `publicVisible` с опубликованным салоном, активным/видимым сотрудником и исключением демо. Поэтому работы команды без опубликованной личной страницы пока не попадают в общую ленту; старые опубликованные личные страницы сотрудников могут обходить скрытие салона/сотрудника в этой выдаче. Требуется отдельная серверная правка единых правил видимости и короткая проверка скрытия. Этим визуальным выпуском API не менялся; дефект не выдаётся за решённый.

Внешний вход Яндекс/VK ID/Telegram, дальнейшие кабинеты, адреса без DaData, карта, PostgreSQL/PostGIS и чат остаются в плане.
