## Что изменено

- `/v2/book/:slug`: услуга → время → контакт. `/v2/s/:slug/book`: услуга → сотрудник/любой свободный → время → контакт. Общая шапка с веткой и пружинным меню, шаги, компактные формы, сводка справа / раскрываемая над шагом. Круглые реальные фото/логотипы, инициалы только при отсутствии изображения. Нет старой шапки, подвала и `.bottom-nav` на записи и `/visit`.
- `/v2/visit#key`: актуальные статусы/данные визита, копирование личной ссылки, отмена активного визита в диалоге, сохранение в кабинет только вошедшим клиентом. После claim переход в «Моё», гостевая ссылка закрывается действующим API.
- Занятое окно возвращает к выбору времени с видимой ошибкой и сохранённым черновиком открытой формы. Повторная отправка защищена от двойного нажатия. Back/Escape сначала закрывают меню/диалог; Back между шагами сохраняет выбор. Фон блокируется; фокус возвращается к кнопке.
- Общие `BookingReference.tsx` / `booking-reference.css`; `SlotCalendar` имеет отдельный визуальный вариант записи, другие календари сохраняются. Анимации учитывают reduced motion, цели дат от 44 px даже на 320 px.

API, серверные роли, квоты, нормализация контакта, защита пересечений/повторов и гостевой ключ в hash/POST сохранены. Новых бизнес-данных в production нет. Контакт не сохраняется при полной перезагрузке — это существующее поведение; возвращается допустимый шаг по публичному предварительному выбору.
