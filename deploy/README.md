# Исторические рецепты production-выпусков

Файлы release-*.sh и release-v2.sh содержат конкретные старые версии/пути. Это история, не универсальная команда выпуска текущего GitHub проекта. Не запускать их автоматически при cloud-настройке.

Current, данные, разрешение и откат всегда сверяются по [CURRENT_STATE](../docs/CURRENT_STATE.md) и последнему соответствующему RELEASE. Подготовка GitHub/cloud не разрешает restart/deploy/миграцию production. Реквизиты в репозиторий не входят.
